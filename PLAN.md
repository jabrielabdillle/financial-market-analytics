# Financial Market Analytics implementation

Software: descriptive market research dashboard for an interview portfolio.

## M1 — trustworthy analytics
Fix initial drawdown baseline and missing-value return handling. Add input validation, explicit observation windows, documented annualization, reproducible CSV/JSON/SQLite exports, deterministic demo data labeled synthetic, and analytical regression tests.

## M2 — interactive application
Build responsive asset/date filters, normalized growth chart, drawdown view, risk/return comparison, correlation table, download controls, and methodology. Apply Taste and Emil guidance, with legible financial tables and restrained motion. Use free static hosting and local SQLite.

## M3 — publish and explain
Run relevant Python and browser checks, publish through GitHub Actions to GitHub Pages, verify the live site, and record actual counts and results. Update README, MEMORY, deployment notes, and interview guide. Each milestone gets a commit, PR and authorized merge.

No investment predictions or performance improvements will be invented. Observed data requires source and adjustment metadata; simulation is always labeled.
